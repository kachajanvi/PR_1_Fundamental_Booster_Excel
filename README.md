# PR_1_Fundamental_Booster_Excel

PR. 1 – Fundamental Booster

Excel Practical Project

Author: Janvi Kacha

Project Overview

This project demonstrates practical knowledge of Microsoft Excel functions and formulas. It includes student grade analysis, sales calculations, employee salary lookup, and date analysis.

Worksheets Included

1. Overview

* Project introduction
* Practical task list
* Functions used
* Legend and instructions

2. Grades

* Classify student grades using Nested IF
* Count students scoring above 60 using COUNTIFS
* Find students with marks above 80 using FILTER
* Calculate Pass/Fail results
* Identify scholarship eligibility
* Rank students among those scoring above 80

Functions Used: IF, AND, OR, COUNTIFS, FILTER, INDEX, MATCH

3. Sales

* Product details and unit prices
* Calculate total sales
* Calculate commission
* Find product prices using VLOOKUP
* Calculate total sales and commission

Functions Used: VLOOKUP, IF, SUM

4. Employees

* Employee information and salary details
* Fetch employee salary using XLOOKUP
* Find joining year and month
* Calculate weekday of joining
* Calculate employee tenure
* Analyze earliest and latest joining dates
* Calculate average salary before 2020

Functions Used: XLOOKUP, INDEX, MATCH, DATE, YEAR, TEXT, DATEDIF

Key Excel Concepts

* Logical Functions
* Lookup Functions
* Conditional Counting
* Date and Time Functions
* Data Analysis
* Basic Calculations

Tools Used

* Microsoft Excel
* Excel Formulas and Functions

Conclusion

This practical project helped develop hands-on experience with Excel formulas, lookup functions, logical conditions, date calculations, and data analysis.
